## 🧱 How I structure apps

```text
lib/src/
├── common/          # shared widgets, styles, services
├── routing/         # go_router config & guards
├── exceptions/      # typed errors + logger
└── features/<feature>/
    ├── presentation/   # pages + widgets (no business logic)
    ├── controller/     # Notifiers / Cubits + state
    ├── application/    # services & use cases
    ├── domain/         # immutable models
    ├── data/           # repositories (REST, GraphQL, Firestore, local DB)
    └── <feature>_barrel.dart   # the only public entry point
```
